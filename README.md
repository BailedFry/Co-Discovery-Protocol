The Co-Discovery Protocol formalises joint-reasoning stability between two agents.

- Co-Discovery Channels

- Motif-Synchronisation  
- Collapse-Avoidance  
- Recurrence-Reinforcement Loops  
- Horizon-Aligned Exploration  
- Regime-Dependent Co-Discovery Modes
